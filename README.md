# LapTech Shop

Online shop for LapTech (Pvt) Ltd — laptops, software and IT services in Harare, Zimbabwe.

Built with Next.js 15 (App Router) + TypeScript + Tailwind CSS + Prisma.

## Getting Started

```bash
cp .env.example .env   # then fill in the values
npm install
npm run db:setup
npm run dev            # http://localhost:3000
```

## Versioning

The app version lives in `version.json` and is bumped by 0.01 on every update:

```bash
npm run version:bump
```
